# Cursor Configuration for Express TypeScript Boilerplate

This directory contains Cursor-specific configuration files to enhance your development experience with this Express TypeScript boilerplate.

## 📁 Files Overview

### `rules`

Main Cursor rules file containing:

- **Code style conventions** (TypeScript, naming, imports)
- **Directory-specific guidelines** for each folder
- **API development patterns** (error handling, responses, validation)
- **Best practices** for Express.js, TypeScript, and project structure
- **Performance & security** guidelines

### `instructions.md`

Detailed development instructions including:

- **Quick start commands** for common tasks
- **Directory templates** with copy-paste code examples
- **Step-by-step workflows** for adding new features
- **Environment setup** guidance
- **Git workflow** with conventional commits

## 🚀 How Cursor Uses These Files

When you're working in this project, Cursor will automatically:

1. **Follow coding conventions** defined in the rules
2. **Suggest appropriate file structures** based on directory guidelines
3. **Generate code** that matches your boilerplate patterns
4. **Recommend best practices** for Express/TypeScript development
5. **Maintain consistency** across your codebase

## 🛠️ Usage Examples

### When creating a new controller:

Cursor will suggest the proper structure with error handling, consistent response format, and service delegation.

### When adding routes:

Cursor will recommend RESTful patterns, proper middleware ordering, and registration in the main routes file.

### When writing services:

Cursor will suggest proper business logic separation, error handling, and TypeScript typing.
